# Filing Watch - releases

Public release channel for Filing Watch (Stock and investment comparison). The source lives in a
private repository; this repo exists only to host the Windows installer and the checksum the
app's auto-updater reads.

Download the latest `FilingWatch-Setup-X.Y.Z.exe` from the
[Releases](https://github.com/jameslilwall1/Stock-Investment-Comparison-public/releases)
page. The installer is signed with a self-signed certificate, so Windows SmartScreen may warn on
first install. Installed copies check for updates themselves and install one only when you
choose to, and only if its checksum and signature match.
